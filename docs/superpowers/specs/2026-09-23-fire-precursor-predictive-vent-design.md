# 화재 징조 예지 → 자동 환기(벤트) 설계

작성 2026-09-23 · 대상 JCC-CCM (스마트 판넬 모니터링)

## 1. 목표

리튬/ESS 열폭주는 **오프가스(H2·VOC 발생) → 온도 상승 → 연기 → 화염** 순서로 진행된다.
가스의 **상승(값+속도)** 을 화염·연기 전에 잡아 **화재 징조를 예지**하고, 위험 단계에서
**환기구(벤트)를 자동 개방**해 가스를 배출·희석함으로써 발화를 예방한다. 이것이 JCC-CCM의
핵심 차별점(예지보전)이다.

핵심 시나리오: **H2 수소센서 + VOC 가스센서가 동반 상승하면 화재 징조로 보고 벤트를 연다.**

## 2. 성공 기준

- 정상 잡음(평상 변동·단발 스파이크)에서는 벤트를 열지 않는다(오탐 억제).
- H2·VOC가 임계 도달 **전에** 동반 상승하면 위험 단계로 올려 벤트를 자동 개방한다(예지=선제).
- 가스가 기준 아래로 내려가 유지되면 벤트를 자동으로 닫는다(복구).
- 판단 근거(어느 신호가 왜)를 항상 기록·표시한다(설명 가능).
- 엣지(CCM)가 서버/인터넷 없이도 벤트를 자율 작동한다. 서버는 교차검증·알림·상향.

## 3. 신호와 특징 (존 = 가스 CCM/판넬 단위)

| 신호 | 특징(feature) | 역할 |
|---|---|---|
| **H2 (%LEL)** | 현재값, 상승속도(Δ/분), 평소대비 z-score | 1차(예지 핵심) |
| **VOC (신규)** | 현재값, 상승속도, z-score | 1차(예지 핵심) |
| 온도 (°C) | 급상승(Δ/분) | 확증 가산 |
| 전류 이상 / 열연기 | 접점/이상 여부 | 확증·극한 강제 |

- **상승속도·z-score = 예지 항**: 절대 임계(늦음) 전에 "평소보다 빠르게 오르는 중"을 잡는다.
  z-score는 기존 `baseline_stats`(중앙값·MAD) 엔진을 재사용한다.
- VOC 단위: **ppm**(0~수천). 경고/위험 기준은 프로파일 기본값으로 두고 설정 override 가능.

## 4. 화재 위험 지수 (FRI 0~100)

각 가스 기여도 `g = clamp(0..1)` 를 세 항의 최댓값 근처로 합성한다:

```
lvl(x)   = ramp(x, warn, alarm)          # warn에서 0.5, alarm에서 1.0
rise(x)  = ramp(dx_per_min, riseWarn, riseAlarm)
anom(x)  = ramp(zscore, 3.0, 6.0)        # 평소대비 급등
g_H2  = max(lvl,rise,anom) for H2
g_VOC = max(lvl,rise,anom) for VOC
co    = (g_H2>0.3 && g_VOC>0.3) ? 0.2*min(g_H2,g_VOC) : 0     # 동반 상승 부스트
temp  = ramp(temp_rise_per_min, tWarn, tAlarm)                # 확증
conf  = (열연기 || 전류이상) ? 0.15 : 0                         # 확증
FRI = 100 * clamp( 0.38*g_H2 + 0.38*g_VOC + co + 0.10*temp + conf )
```

- 가중치·임계는 설정(환경변수/기본값)으로 조정 가능. 위 값은 초기값.
- FRI는 **존별**로 계산(그 CCM에 H2·VOC가 함께 있을 때 co-boost 유효).

## 5. 단계와 자동 작동 (단계적 자동)

| 단계 | 조건(예) | 조치 |
|---|---|---|
| 정상 normal | FRI < 30 | — |
| 주의 watch | 30 ≤ FRI < 55, 또는 한 가스만 급등 | 경고 이벤트·알림(화면/로그) |
| **위험 danger** | FRI ≥ 55, 또는 **H2·VOC 동반 상승** | **벤트 자동 개방** + 위험(crit) 경보·알림 |
| 극한 critical | FRI ≥ 80, 또는 가스 ≥ alarm_max & (온도 급상승 \| 열연기) | 벤트 유지 + 차단기/소화 연동 신호 + 즉시 상향 |
| 복구 recover | FRI < 20 이 유지시간(기본 60s) 지속 | 벤트 자동 닫힘 · "환기 완료" |

- 히스테리시스: 개방은 FRI≥55, 닫힘은 FRI<20 유지 → 경계에서 깜빡임 방지.
- 사람 오버라이드: 수동으로 벤트 열기/닫기 가능. 수동 상태는 자동 로직보다 우선하며,
  일정 시간/조건에서 자동 복귀(정책은 구현 시 확정, 기본: 수동 우선 유지, 사용자가 해제).

## 6. 아키텍처 (엣지 + 서버 이중화)

**포터블 코어** — 순수 함수, 부작용 없음:
```
assess_fire_risk(signals, history, cfg) -> {
  fri: 0..100, stage: normal|watch|danger|critical,
  reasons: ["H2 급상승 z=..","VOC 동반 상승",..],
  action: none|open_vent|hold_vent|close_vent
}
```
- `firmware/jcc_ccm/`(엣지)와 `server/jcc_server/`(서버) 양쪽에서 **같은 로직**을 쓴다.
  (클린룸 원칙 유지 — 공개 규격·자체 구현)
- **엣지(CCM)**: 자기 존 신호로 매 주기 assess → stage≥위험이면 **벤트 릴레이 즉시 작동**.
  서버 없이 자율. 결과·조치를 서버로 보고.
- **서버**: 텔레메트리로 재계산(교차검증) → 경보 생성·상향·알림·이벤트 로그, 원격 벤트 명령.
  엣지가 이미 열었으면 확인만.

## 7. 새 하드웨어 모델

- **VOC 센서 프로파일**: 가스 계통 CCM(ccm-2661)에 추가. emit `voc`(ppm, kind=voc, warn/alarm).
- **벤트 액추에이터(릴레이 출력)**: 존별 1개. 상태 `열림/닫힘`.
  - 명령: `vent_command(zone, open|close, reason, by)` — 이벤트 로그(vent_open/vent_close/vent_hold).
  - **fail-safe = 개방**: 정전·통신두절 시 벤트는 열림(가스 축적 상황의 안전측). 설정 가능.
  - storage에 `_vent_state`(존→open/closed/auto|manual) 유지, 재시작 복원.

## 8. 대시보드

- **화재 예지 카드**(개요/존): FRI 게이지 + 단계 배지 + 기여 신호(reasons) + **벤트 상태**.
- **벤트 수동 오버라이드** 버튼(열기/닫기) — 조작은 이벤트 로그.
- 위험 단계면 해당 존 노드 강조(기존 severity 색 재사용, 번짐 글로우 금지=솔리드).
- 데모 HUD/티커에 `🔥 화재 징조 감지 · 벤트 개방` 등 이벤트 표시.

## 9. 데모/시뮬레이션

- `demo.py`·`web/demo-api.js`: 드물게 **화재-징조 에피소드** 발생 — H2·VOC 동반 상승 +
  온도 상승 → FRI 급등 → 위험 단계 → **벤트 자동 개방**(애니메이션) → 환기로 가스 하강 →
  복구(벤트 닫힘). 서버·데모 로직 동일하게 유지.
- 평상시엔 FRI 낮게 유지(오탐 없음).

## 10. 테스트

FRI 코어 단위테스트:
- 정상 잡음 → normal, 벤트 안 열림
- H2만 급등 → watch(경고), 벤트 안 열림
- **H2+VOC 동반 상승 → danger, open_vent**
- 가스 임계초과+온도급상승/열연기 → critical, hold_vent + 상향
- 가스 하강 유지 → recover, close_vent
- 히스테리시스(경계 깜빡임 없음)
- 상승속도만으로(절대값 임계 아래) 조기 danger 진입(예지 검증)

통합테스트(서버): 에피소드 텔레메트리 → 벤트 개방 이벤트 → 복구, 재시작 후 벤트 상태 복원.
회귀: 기존 firmware/서버 테스트 전부 유지.

## 11. 설정(환경변수, 기본값 안전측)

- `JCC_FIRE_AUTOVENT` (기본 1): 자동 벤트 on/off (off면 감지·알림만).
- `JCC_FIRE_OPEN_FRI`(55) / `JCC_FIRE_CLOSE_FRI`(20) / `JCC_FIRE_CRIT_FRI`(80)
- 가스별 warn/alarm/상승속도 임계는 프로파일 기본값 + settings override.
- `JCC_VENT_FAILSAFE`(open): 통신두절 시 벤트 기본 상태.

## 12. 범위(YAGNI)

- 이번 범위: FRI 코어 + VOC/벤트 모델 + 서버 통합 + 데모/대시보드 + 테스트.
- 이번 범위 밖: 실제 소화설비/차단기 물리 연동(신호만 발생), ML 모델, 다존 상호작용 고급화,
  실기(실센서) 캘리브레이션(실물 검증 시).
