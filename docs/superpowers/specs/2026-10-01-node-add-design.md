# 노드 추가 — 장비 검색 + 센서 직접 지정

## 요청

상단 '추가' 메뉴(그림용 노드 8종)가 어수선하다 → '노드 추가' 하나. 팝업에서 [검색]으로 새로 연결된 장비를 찾고,
검색에 안 잡히면 수동으로 연결. 결정: 수동 연결 = **센서 직접 지정**(RS485 주소·레지스터 / Modbus TCP IP·포트),
그림용 노드는 메뉴에서 뺀다(이미 그린 것은 유지).

## 구성

- `sensor_spec.py`(서버 정본, CCM 사본은 sync_edge_core) — 서버·CCM 같은 규격 검사
- 서버 `manual_sensors.py` — CCM별 목록·버전, 인벤토리 반영(같은 주소의 '추정'은 대체, 재탐색에도 유지),
  텔레메트리 응답으로 하향, CCM 보고로 적용/거부 상태
- 펌웨어 `manual.py` — 받아서 검사·적용·파일 저장(재부팅 유지)·보고, Modbus TCP 버스 추가
- API: GET/POST `/api/sensor/manual`, GET `/api/sensor/profiles` (모두 JCC 관리자)
- 운영 서버의 검색은 가상 탐색을 돌리지 않고 CCM이 보고한 장비 요약(가짜 장비가 섞이지 않게)
- 화면: 검색 결과는 손볼 것(추정·직접 지정·기존 CCM의 새 센서)만 펼침, 직접 지정 목록·상태·두 번 눌러 삭제
