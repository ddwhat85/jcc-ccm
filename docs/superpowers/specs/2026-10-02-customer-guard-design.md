# 고객 화면 「JCC GUARD」 — 안심 계기판 설계

날짜: 2026-10-02 · 상태: 사용자 승인(A안 「안심 계기판」, "응 진행해")

## 목적

고객이 보고 "돈 낼 만하다"고 느끼는 화면. 이미 산 고객(계약 연장·추가 구매)과 아직 안 산 잠재 고객(영업 시연)이
**같은 화면**을 본다. 고객이 돈을 내는 이유 네 가지(사용자 확인 2026-10-02)를 모두 보여 준다:
화재·사고 예방 · 사람 대신 24시간 감시 · 점검·보험·감사 자료 · 설비 정지·수리비 절감.

직원 화면(`server/static/index.html`, '전기 도면 시트')은 그대로 둔다. 고객 화면은 별도 세계다.

## 시각 방향 (선택: A · 안심 계기판)

고급차 계기판. 어두운 바탕(밤) + 밝은 낮 화면. 큰 원형 '안심 지수' 하나가 중심. 숫자는 가는 굵기(300),
글은 Gothic A1. 상태색: 안심 초록 `#7fd1a8`(밤)/`#3fae7d`(낮), 주의 호박 `#e9b45a`, 위험은 JCC 빨강 계열(위험일 때만 화면 전체가 붉어짐).
이모지 아이콘 금지(선 아이콘). 시안: `.superpowers/brainstorm/…/a-screens.html`, `a-moments.html`.

## 화면

1. **첫 화면** — 안심 지수 링 + 지금 무슨 일인지 한 문장 + 이번 달 성과 3개(미리 잡은 징조 · 스스로 한 조치 · 평균 대응)
   + 판넬 목록(문제 있는 것부터) + JCC 연락 카드(담당 · 다음 정기 점검 D-day).
2. **지수의 근거**(지수를 누르면 아래에서 올라오는 시트) — 100점에서 깎인 항목을 한 줄씩.
3. **판넬 상세** — 온도·습도·화재 징조·단자 발열을 숫자 + 말("결로 주의", "낮음") + 남은 여유 + 판넬·JCC가 한 일 타임라인.
4. **이번 달 지켜낸 것** — "이번 달, JCC가 N시간 지켰습니다" + 장부(미리 잡은 징조 · 스스로 한 조치 · 원격 확인 · 평균 대응)
   + 월간 보고서 · 점검 보고서 열기. 달 넘기기.
5. **위험이 생긴 순간** — 활성 위험 경보가 있으면 첫 화면이 이 상태로 바뀐다. 무엇을 감지했나 → 판넬이 한 일 → JCC가 한 일 →
   지금 할 일. 버튼: "JCC에 전화"(tel:), "현장 확인했어요"(담당자 등급만 — 경보 확인 + 메모 '고객 현장 확인').
6. **로그인** — "○○공장을 지켜보고 있습니다." 고객 화면 자체 로그인.
7. **PC** — 왼쪽 계기판 고정 · 오른쪽 판넬 카드 격자.
8. **영업 시연 모드**(시연판에서만) — 가상 공장 + "그날 밤" 이야기 재생(화재 징조 · 단자 과열 · 장마철 결로). 실제 화면 위에 시간 자막.

고객이 할 수 있는 조작은 **보기 + 경보 확인/메모**뿐. 벤트·히터 등 출력 조작은 넣지 않는다(안전 — 규칙과 JCC가 맡는다).

## 안심 지수 (투명한 감점식)

100에서 지금 상태만큼 뺀다(0 미만은 0). 각 감점은 이유 한 줄과 함께 돌려준다.
한 판넬의 경보 감점은 위험 최대 −40, 주의 최대 −15(화재 때 센서 여럿이 함께 넘어도 0점이 되지 않게 — 구현 중 추가).
링 색: 위험 경보 → 빨강, 지켜보는 판넬이 있으면 호박, 부품 여유·점검 일정 같은 관리 감점만 있으면 초록(상태 문장 '안전'과 맞춤).

| 항목 | 감점 |
|---|---|
| 활성 위험 경보 1건마다 | −20 |
| 활성 주의 경보 1건마다 | −5 |
| 끊긴 CCM 1대마다 | −10 |
| 화재 징조 지켜보는 중(watch/warning) | −5 |
| 결로·단자 발열 주의 | −3 |
| 부품 남은 여유 60일 이내 | −3 |
| 정기 점검 기한 지남 | −5 |

상태 문장: 위험 경보 있음 → "위험 — ○○에서 △△" / 감점 있음 → "판넬 N면 · M곳 지켜보는 중" / 없음 → "모든 판넬 안전합니다".

## 숫자의 출처 (지어내지 않는다)

- 지켜본 시간: 그 달 1일(또는 첫 수신)부터 지금까지 감시한 시간 = 시간 × 업타임.
- 순찰 비교: "하루 3회 순찰 기준 추정"을 화면에 밝혀 적는다(추정값임을 표시).
- 미리 잡은 징조: 월간 리포트의 `precursors`(화재·단자·결로 예지 감지).
- 스스로 한 조치: `vent_auto`(환기) + 결로 히터·팬 작동 이벤트(`dew_actuate`, `edge_actuate`).
- 원격 확인·해결: 자가복구 성공(`self_heal`).
- 평균 대응: 위험 경보 평균 확인 시간(`ack_min_avg`).
- 판넬 값: 최신 읽기(온도·습도) + 예지 상태(화재·단자·결로) + `rul.panel_view`.
- 위험 순간 단계: 경보 발생 시각, 같은 판넬의 `vent_open`/`edge_actuate` 이벤트, `acked_at/acked_by`, `escalate`(알림 발송) 이벤트.
- 연락처: 환경변수 `JCC_SUPPORT_PHONE`(없으면 전화 버튼 숨김). 담당: 마지막 정기 점검자(없으면 "JCC 관제실").

## 구조

- **서버 `server/jcc_server/guard.py`** — `guard_view(storage, panels, customer_name, now)` →
  `{site, index:{score, color, items[]}, state, panels[], month:{…}, incident|null, contact, next_inspection}`.
  기존 `fleet`, `monthly.build_monthly` 계산 부품, `rul`, `alarms`, `events`를 재사용. 순수 함수 위주(테스트 쉬움).
- **경로** — `GET /guard`(화면, 공개 껍데기), `GET /api/guard?customer_id=`(read; 고객은 자기 범위, 직원은 customer_id로 미리보기,
  없으면 전체), `GET /api/guard/month?period=YYYY-MM`(지켜낸 것 달 넘기기). 경보 확인은 기존 `/api/alarm/ack`.
- **화면 `server/static/guard.html`** — 단일 파일(직원 화면과 같은 방식), 자체 로그인(`/api/login` 재사용),
  5초마다 `/api/guard` 갱신. 고객 계정이 직원 화면(`/`)에 로그인하면 `/guard`로 보낸다. 직원 화면 도구 메뉴에 "고객 화면으로 보기".
- **글꼴** — Gothic A1 300(가는 숫자)을 `static/fonts/`에 추가(OFL, 같은 저장소의 기존 글꼴과 같은 출처).
- **시연판** — `tools/build_web.py`가 `web/guard.html` + `web/guard-artifact.html`(인라인) 생성. `web/demo-api.js`에 `/api/guard`
  모의 응답과 이야기 3편 재생(기존 `JCC_DEMO.episode`를 자막과 함께). 별도 아티팩트로 공개.
- **디자인 규칙** — 고객 화면 전용 토큰은 `guard.html` 안 `:root`(밤)/`[data-theme=light]`(낮). DESIGN.md에 '고객 화면' 절 추가.

## 오류·빈 상태

- 판넬 없음: "아직 연결된 판넬이 없습니다 — 설치가 끝나면 이곳에서 24시간 지켜봅니다."
- 서버 연결 끊김: 링 회색 + "연결을 다시 잇는 중 — 판넬은 현장에서 스스로 지키고 있습니다"(엣지 규칙은 서버 없이도 동작).
- 월간 수치가 없는 달(설치 첫 달 등): 장부에 "이번 달 기록이 쌓이는 중" 표시, 0을 성과처럼 보이지 않게.
