# JCC-CCM 펌웨어 변경 기록

원격 업데이트(OTA)는 이 버전 번호로 대상과 롤백을 판단한다. 현장에 내보내기 전에
`jcc_ccm/__init__.py`의 `__version__`을 올리고 여기에 무엇이 바뀌었는지 적는다.
번들은 `python tools/ota_build.py`(서명 키는 저장소·서버·CCM 어디에도 두지 않는다).

## 0.2.0 — 첫 현장 배포 기준 (2026-10-03)

0.1.0은 개발 중 기본값이었다. 현장에 처음 올리는 판이 0.2.0이다.

- **엣지 예지**: 서버 없이 CCM이 직접 화재 징조(H2·VOC·CO + 온도)·접점 발열·결로를 판정해
  벤트·히터·팬을 구동(서버 판정 코어와 같은 사본 — `tools/sync_edge_core.py`)
- **출력 작동 확인**: 명령 후 되읽기·재시도, 안 움직이면 '작동 실패' 보고(ActuatorGuard)
- **원격 설정**: 절대 한계 검증 후 적용·저장·보고, 놓친 사고가 있으면 서버가 설정을 거부
- **원격 업데이트**: JCC 서명 번들만 설치, 시험 부팅 실패 시 자동 롤백
- **센서 직접 지정**: 검색에 안 잡히는 센서를 RS485 / Modbus TCP 주소로 지정(실기 확인 필요)
- **Modbus TCP 장비 끊김**: 30초 대기 후 재시도 — 수집 루프를 늦추지 않음
- **부팅 시각 전송**(`boot_ts`): 서버가 감시 끊김을 '통신만 끊김'(큐에 쌓였다 나중에 올라옴)과 '전원이 꺼졌다 켜짐'으로 가른다
